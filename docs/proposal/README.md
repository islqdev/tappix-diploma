# Proposal Draft

## Topic

Development of an Information System for Managing Customer Relationships in
Small Businesses Through Digital Loyalty Programs.

## Problem and Audience

Target users are small-business owners, employees and guests in Kazakhstan.
The proposed problem is inconsistent tracking of visits, rewards and returning
customers across paper cards and manual records. This is a hypothesis from the
project brief, not a finding from completed interviews.

## Objective and Outcomes

Build and evaluate a multi-tenant web system that records loyalty operations,
provides a guest wallet, and shows owners reproducible customer metrics.
Deliver source code, schema/migrations, API contracts, tests, deployment and
recovery instructions, research comparisons and an evaluation report.

## Scope

Four roles; owner-managed programs for visits, points and discounts; multiple
independent guest cards; branch/staff permissions; platform-assigned plans,
usage limits and a seven-day trial; analytics derived from recorded events.

Not included in the first version: payments, bank-card storage, cross-company
point transfers, AI recommendations, native mobile applications or automatic billing.

## Evidence Still Needed

Real business interviews or a documented pilot agreement, research literature,
comparison of alternatives, agreed evaluation metrics and supervisor feedback.
The existing prototype is a design reference, not evidence of market demand.
