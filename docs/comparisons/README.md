# Comparison Plan

No completed competitor or technology comparison is claimed here.

Compare 3-5 real alternative solutions using 6-10 consistent criteria. Include
paper cards/manual records and doing nothing, not only subscription products.
Capture dated primary sources for pricing and feature claims. Mark unverified
features as unknown, not absent.

Suggested product criteria: target customer, setup effort, guest onboarding,
loyalty mechanics, branch/staff permissions, analytics definitions, data export,
recurring and usage-based costs, integration support and regional suitability.

Compare at least three architectural choices with 2-3 alternatives each, recording
constraints and trade-offs. The requested stack is a project constraint, not proof
that every alternative is inferior. Promote reviewed decisions into ADRs.
