## Журнал обратной связи

Содержательных замечаний руководителя пока нет. Разрешение использовать ИИ,
сообщённое Арматом, не заменяет отзыв на отчёт. После обсуждения зафиксировать
дату, замечание, принятое решение, ссылку на изменение и подтверждение автора.
Не подписывать документ за руководителя и не заполнять вымышленный отзыв.

## Перед передачей

- Проверить, что отправляются PDF/DOCX и изображения из автономного пакета,
  а не рабочая база, конфигурация или архив старого приложения.
- Попросить Ерсұлтана лично проверить PR; после одобрения выполнить merge по порядку.
- Поставить pre-defense-1 только на принятую версию и записать SHA отдельно.
- Сообщить руководителю о двух незакрытых эмпирических пунктах и получить решение.
- При необходимости доступа к GitHub получить её логин; приватную ссылку одной
  отправкой нельзя сделать доступной без изменения прав.
